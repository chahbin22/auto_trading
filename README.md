# 토스증권 일봉 백테스트와 RSI 모의 운용

토스증권 Open API로 IONQ, RXRX, BBAI의 일봉을 수집합니다. 종목별 전략과 세 종목을 합친 포트폴리오의 성과를 비교하고, RSI 전략의 가상 주문과 체결을 모의 장부에 기록합니다. 실제 주문을 전송하지 않습니다.

## 프로젝트 진행 현황

| 단계 | 상태 | 확인한 범위 |
|---|---|---|
| 일봉 수집·저장 | 구현 및 실행 확인 | 세 종목의 일봉 CSV 저장과 SMA 조회 |
| 전략·포트폴리오 백테스트 | 구현 및 실행 확인 | 2024~2026년 연도별 비교, 2025년부터 2026년까지 잔액과 보유 상태를 이어가는 연속 비교 |
| RSI 모의 운용 | 초기 운용 중 | 기존 보유 수량으로 장부를 시작하고 일봉 2개를 기록했습니다. 실제 일봉으로 처리한 첫 가상 체결은 확인 대기 중입니다. |
| macOS 앱·예약 갱신 | 로컬 설치 및 일부 확인 | 앱의 장부 표시와 수동 실행의 확정 대기 처리를 확인했습니다. 예약 실행에서 새 일봉이 수집되어 장부에 추가되는 과정은 확인 대기 중입니다. |
| 실거래 | 미구현 | 현재 프로젝트는 백테스트와 모의 운용을 지원합니다. |

다음 확인 항목은 **예약 실행으로 새 확정 일봉이 장부에 추가되는지**와 **첫 가상 주문의 신호일·다음 봉 시가·수수료가 정확히 기록되는지**입니다.

## 설치 및 설정

Python 3.10 이상이 필요합니다. 프로젝트 폴더에서 가상환경을 만들고 의존성을 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp -n .env.example .env
```

`.env`에 토스증권 Open API의 `TOSS_CLIENT_ID`와 `TOSS_CLIENT_SECRET`을 입력합니다. 토스증권에 실행 환경의 공인 IP가 등록되어 있어야 합니다.

## 일봉 수집 및 조회

```bash
python main.py collect IONQ
python main.py collect --pages 5
python main.py inspect IONQ --through '2026-11-09T14:00:00+09:00'
```

`collect`는 토큰을 한 번 발급받고 종목당 기본 2페이지를 조회합니다. 종목을 생략하면 세 종목을 처리합니다. 성공한 조회 결과는 `data/`의 해당 CSV를 교체하므로 더 적은 페이지로 수집하면 저장 범위도 줄어듭니다. 조회 오류나 빈 응답이 발생한 종목의 기존 CSV는 보존합니다.

`inspect`는 로컬 CSV에서 SMA(5/10/20)를 계산합니다. 일봉 시각은 토스 응답 그대로 저장하며, `--through`는 지정 시각의 봉까지 포함합니다. 최신 봉은 조회 시점에 따라 값이 달라질 수 있으므로 마지막 확정 봉의 시각을 입력하세요.

## 백테스트

### 종목별 비교

SMA(5/20), 20거래일 모멘텀, RSI(14) 30/70, 매수 후 보유를 비교합니다. 전략 신호는 확정 종가를 기준으로 계산하고 다음 봉 시가에 가상 체결합니다. 기본 시작 자금은 10,000 USD이고 편도 비용은 0.10%입니다.

```bash
python backtest.py IONQ \
  --through '2026-11-09T14:00:00+09:00' \
  --export-trades
```

`--from`으로 평가 시작일을 지정합니다. `--export-trades`는 SMA 거래별 체결 시각과 비용 차감 손익을 `IONQ_sma_trades.csv`에 저장합니다. Ridge는 `--ridge-validation-from`과 `--from`을 함께 지정해 추가하며, `--export-ridge`로 Ridge 거래와 일별 예측을 저장합니다.

### 포트폴리오 비교

`--weights`는 IONQ, RXRX, BBAI 순서의 시작 비중(%)입니다. 세 종목의 주식 평가액과 현금을 매일 합산해 수익률과 최대 낙폭을 계산합니다. 보유 출발 전략은 첫 평가 봉 시가로 시작 수량을 계산하며, 이미 보유한 물량에는 시작 매수 비용을 부과하지 않습니다.

```bash
python portfolio_backtest.py \
  --weights 40 35 25 \
  --continuous-from '2025-01-01T00:00:00+09:00' \
  --through '2026-11-09T14:00:00+09:00'
```

- `--continuous-from`은 해가 바뀌어도 잔액과 보유 상태를 이어갑니다. Ridge와 GBRT는 연도별로 갱신하며, 직전 1년으로 설정을 검증하고 그보다 앞선 데이터로 학습합니다.
- `--years 2024 2025 2026`으로 바꾸면 해마다 동일한 시작 비중과 자금으로 다시 평가합니다.
- `--rsi-only`를 추가하면 모델 학습 없이 계속 보유와 RSI 보유 출발만 비교합니다.

## RSI 모의 운용

처음에는 확정 일봉 시각과 모의 계좌의 시작 보유 수량을 지정합니다. 아래 수량은 예시이며 입력 순서는 IONQ, RXRX, BBAI입니다.

```bash
python paper_rsi.py \
  --start '2026-11-12T00:00:00+09:00' \
  --shares 10 20 30 \
  --through '2026-11-12T14:00:00+09:00'
```

이후에는 `--through`만 지정합니다. 이미 처리한 봉을 다시 실행해도 체결이 중복되지 않습니다.

```bash
python paper_rsi.py --through '2026-11-13T14:00:00+09:00'
```

보유 중 RSI가 70 이상이면 가상 매도하고, 현금 상태에서 RSI가 30 이하이면 가상 매수합니다. 장부에는 신호와 다음 봉 시가 체결, 수수료, 보유 수량, 현금, 계속 보유 기준의 평가액을 기록합니다.

`python paper_rsi_refresh.py`는 기존 `paper_rsi_ledger.json`을 이어서 갱신합니다. 토스 API에서 받은 최근 확정 일봉을 기존 CSV와 병합하고, 세 종목의 새 일봉 시각을 확인한 뒤 모의 장부를 처리합니다. macOS 메인 창과 오전 8시 30분 예약은 별도 설치본을 사용합니다. 현재 저장소에는 앱 빌드 소스와 설치 스크립트가 포함되어 있지 않습니다.

## 코드 구성

| 파일 | 역할 |
|---|---|
| `toss_client.py` | 토큰 발급과 일봉 API 요청 |
| `storage.py` | 종목별 일봉 CSV 저장·조회 |
| `indicators.py` | SMA 계산 |
| `main.py` | 일봉 수집과 조회 명령 |
| `backtest.py` | 단일 종목 백테스트와 모델 예측 |
| `portfolio_backtest.py` | 포트폴리오 백테스트와 최대 낙폭 계산 |
| `paper_rsi.py` | RSI 신호, 가상 체결, 모의 장부 관리 |
| `paper_rsi_refresh.py` | 확정 일봉 병합과 기존 장부 갱신 |

커밋 전에는 `.env`, `data/`, 모의 장부 JSON, 실행 로그가 스테이징에 포함되지 않았는지 확인하세요.
